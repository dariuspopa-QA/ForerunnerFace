# Working style (Darius)
- At a design fork pick the best option yourself, say which in one line, keep going. Only irreversible steps
  (pushing to the watch, publishing, deleting history, git push) wait for Darius; when waiting, say so plainly.
- Every change to a face includes its store listing: update `store/description.txt`, `CHANGELOG.md`, and rerun
  `FaceCore/tools/store-shots.ps1 -Face X` before calling it done (skill: `.agents/skills/finish-face-change`).
- Darius gives terse visual feedback ("looks bad"): ask what specifically is wrong instead of guessing again.
